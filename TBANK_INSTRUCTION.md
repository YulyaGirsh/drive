# Инструкция по получению данных для Т-банка

## Где найти правильные данные в личном кабинете:

1. **Войдите в личный кабинет Т-банка Бизнес**: https://business.tbank.ru/

2. **Откройте раздел "Оплата"** → **"Операции"**: https://business.tbank.ru/oplata/operation

3. **Найдите раздел "Настройки интеграции" или "API настройки"**

4. **Вам нужны следующие данные:**

   - **TerminalKey** (или Terminal ID) — это идентификатор терминала
   - **SecretKey** (или Secret) — это секретный ключ для подписи

## ⚠️ ВАЖНО:

- SecretKey — это **НЕ** пароль от личного кабинета!
- Это специальный ключ, который генерируется в разделе настроек интеграции
- Обычно его можно скопировать только один раз при создании терминала
- Если ключ потерян, нужно сгенерировать новый

## Где искать секретный ключ:

1. В личном кабинете: **Настройки** → **Интеграция** → **API**
2. Или: **Мои приложения** → **Оплата** → **Настройки терминала**
3. Или обратитесь в техническую поддержку Т-банка

## После получения правильных данных:

1. Обновите файл `config.env`:
   ```
   TBANK_TERMINAL_KEY=ваш_правильный_terminal_key
   TBANK_SECRET_KEY=ваш_правильный_secret_key
   ```

2. Сообщите мне новые данные, и я обновлю код.
