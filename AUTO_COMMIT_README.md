# Автоматические коммиты с русскими комментариями

## Использование

### Вариант 1: Python скрипт (рекомендуется)

```bash
# Простой коммит без пуша
python auto_commit.py

# Коммит с автоматическим сообщением и пуш
python auto_commit.py --push

# Коммит с кастомным сообщением
python auto_commit.py "Исправление: Добавлена новая функция"

# Коммит с кастомным сообщением и пуш
python auto_commit.py --push "Обновление: Улучшена производительность"
```

### Вариант 2: Batch скрипт (Windows)

```cmd
# Простой коммит
auto_commit.bat

# Коммит с пушем
auto_commit.bat --push

# Коммит с сообщением
auto_commit.bat "Исправление бага"
```

## Автоматический пуш после коммита

Если вы хотите, чтобы после каждого коммита автоматически выполнялся пуш на GitHub, используйте git hook:

```bash
# На Linux/Mac
chmod +x .git/hooks/post-commit

# На Windows хук уже настроен
```

**Внимание:** Автоматический пуш может быть нежелателен в некоторых случаях. Если хотите отключить, удалите или переименуйте файл `.git/hooks/post-commit`.

## Интеграция с редактором

### VS Code

Добавьте в `tasks.json`:

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Auto Commit",
            "type": "shell",
            "command": "python auto_commit.py --push",
            "problemMatcher": []
        }
    ]
}
```

### Автоматический коммит при сохранении

Можно настроить автоматический запуск скрипта при сохранении файлов через расширения VS Code или другие инструменты.

## Формат сообщений коммитов

Скрипт автоматически создает сообщения в формате:
- `Обновление: Изменены файлы (file1.py, file2.py) - 2025-01-02 15:30:45`
- Или используйте свой формат через параметр командной строки
