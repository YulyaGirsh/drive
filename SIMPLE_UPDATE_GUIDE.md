# Простое руководство: Обновление без регистрации в Docker Hub

## Текущая ситуация

✅ Код уже обновлен на сервере  
❌ Не можем скачать образ PostgreSQL из-за лимита Docker Hub

## Решение 1: Подождать (самый простой способ)

Лимит Docker Hub обновляется каждые 6 часов. Подождите **30-60 минут** и выполните:

```powershell
.\update_server_postgres.ps1
```

Или используйте автоматический скрипт ожидания:

```powershell
.\wait_and_update.ps1
```

Скрипт будет проверять каждые 10 минут и автоматически попробует запустить контейнеры, когда лимит обновится.

## Решение 2: Быстрая регистрация в Docker Hub (2 минуты)

Если не хотите ждать:

1. **Откройте** https://hub.docker.com/signup
2. **Зарегистрируйтесь** (email + пароль, бесплатно)
3. **Подтвердите email** (если требуется)
4. **Запустите скрипт:**
   ```powershell
   .\docker_login_on_server.ps1
   ```
   Введите логин и пароль Docker Hub

После авторизации лимит увеличится с 100 до 200 запросов в 6 часов.

## Решение 3: Проверить, может образ уже есть

Иногда образ уже был скачан ранее. Проверьте на сервере:

```bash
ssh root@89.23.99.152
docker images | grep postgres
cd /home/easydrive
docker-compose up -d
```

## Что происходит сейчас?

- ✅ **Код обновлен** - все изменения из GitHub уже на сервере
- ✅ **PostgreSQL настроен** - конфигурация готова
- ⏳ **Ждем** - пока можно будет скачать образ PostgreSQL

## После запуска контейнеров

Проверьте статус:

```bash
ssh root@89.23.99.152
cd /home/easydrive
docker-compose ps
docker-compose logs -f
```

## Рекомендация

**Самый быстрый способ** - зарегистрироваться в Docker Hub (2 минуты, бесплатно). Это решит проблему навсегда.

**Если не хотите регистрироваться** - просто подождите 30-60 минут и запустите `.\update_server_postgres.ps1` снова.
