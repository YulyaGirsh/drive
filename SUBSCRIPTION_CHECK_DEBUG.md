# Диагностика проблемы с проверкой подписки на канал

## Возможные причины проблемы

### 1. Бот не является администратором канала

**Самая частая причина!** Бот должен быть администратором канала `@avtoshkolavtelefone` для проверки подписок.

**Как проверить:**
1. Откройте канал `@avtoshkolavtelefone` в Telegram
2. Перейдите в настройки канала → Администраторы
3. Убедитесь, что ваш бот добавлен как администратор

**Как исправить:**
1. Добавьте бота как администратора канала
2. Дайте боту права на просмотр участников (не обязательно быть модератором)

### 2. Неправильное имя канала

Проверьте, что канал называется именно `@avtoshkolavtelefone` (без пробелов, с маленькой буквы).

### 3. User ID не передается

Если приложение открыто не в Telegram Mini App, `user_id` будет `null`, и проверка не сработает.

**Решение:** Приложение должно открываться через Telegram бота.

### 4. Ошибка в логах сервера

Проверьте логи сервера при попытке проверки подписки. Должны быть сообщения:
- `🔍 Проверяем подписку: user_id=..., channel=@avtoshkolavtelefone`
- `📥 Ответ от Telegram API: {...}`
- `✅ Статус подписки: ...`

## Как проверить работу

### Через консоль браузера

1. Откройте приложение в Telegram
2. Нажмите F12 (или откройте DevTools)
3. Перейдите на вкладку Console
4. Нажмите на иконку "Билеты"
5. Смотрите логи:
   - `🔍 Начинаем проверку подписки...`
   - `📤 Отправляем запрос на /api/check-channel-subscription...`
   - `📥 Ответ от сервера получен`
   - `📦 Полный результат от сервера: {...}`

### Через логи сервера

В логах сервера должны быть:
```
🔍 Проверяем подписку: user_id=123456789, channel=@avtoshkolavtelefone
📡 URL запроса: https://api.telegram.org/bot.../getChatMember?chat_id=@avtoshkolavtelefone&user_id=123456789
📥 Ответ от Telegram API: {'ok': True, 'result': {'status': 'member', ...}}
✅ Статус подписки: member, Подписан: True
```

## Статусы подписки

Telegram API возвращает следующие статусы:
- `member` - пользователь подписан ✅
- `administrator` - пользователь администратор ✅
- `creator` - пользователь создатель канала ✅
- `left` - пользователь не подписан ❌
- `kicked` - пользователь заблокирован ❌
- `restricted` - пользователь ограничен (может быть подписан) ✅

## Быстрая проверка через API

Можно проверить вручную через curl:

```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/getChatMember?chat_id=@avtoshkolavtelefone&user_id=<USER_ID>"
```

Замените:
- `<BOT_TOKEN>` - токен вашего бота
- `<USER_ID>` - ID пользователя (можно получить из `tg.initDataUnsafe.user.id`)

## Решение проблемы

1. **Убедитесь, что бот - администратор канала**
2. **Проверьте логи сервера** - там будет точная ошибка
3. **Проверьте консоль браузера** - там будет видно, что возвращает сервер
4. **Убедитесь, что приложение открыто через Telegram** (не в обычном браузере)
