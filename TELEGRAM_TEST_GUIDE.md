# 🔍 Руководство по тестированию подписки в Telegram

## Способы тестирования:

### 1. 📱 Через Telegram Mini App (рекомендуется)

**Вариант A: Через бота**
1. Найдите бота в Telegram (если у вас есть бот)
2. Отправьте команду `/start` или нажмите кнопку "Открыть приложение"
3. Перейдите на страницу `telegram_test.html`

**Вариант B: Прямая ссылка (если настроен webhook)**
```
https://your-domain.com/telegram_test.html
```

### 2. 🌐 Через браузер (для отладки)

1. Откройте `http://localhost:8000/test_subscription.html`
2. Введите ваш Telegram User ID
3. Нажмите "Проверить подписку"

### 3. 🔧 Как узнать свой Telegram User ID

**Способ 1: Через бота @userinfobot**
1. Найдите бота @userinfobot в Telegram
2. Отправьте любое сообщение
3. Бот пришлет ваш User ID

**Способ 2: Через @getidsbot**
1. Найдите бота @getidsbot в Telegram
2. Отправьте любое сообщение
3. Бот пришлет ваш User ID

**Способ 3: Через веб-версию Telegram**
1. Откройте web.telegram.org
2. Войдите в свой аккаунт
3. Откройте консоль разработчика (F12)
4. Выполните: `window.Telegram.WebApp.initDataUnsafe.user.id`

## 🐛 Отладка проблем

### Проблема: "Бот не может проверить подписку"

**Решение:**
1. Убедитесь, что бот добавлен в администраторы канала @avtoshkolavtelefone
2. Проверьте, что у бота есть права на просмотр участников канала
3. Убедитесь, что канал публичный

### Проблема: "Пользователь не найден"

**Решение:**
1. Убедитесь, что пользователь подписан на канал
2. Проверьте правильность User ID
3. Убедитесь, что канал не приватный

### Проблема: "Ошибка 400"

**Решение:**
1. Бот не является администратором канала
2. Канал приватный
3. Неправильный username канала

## 📋 Чек-лист для настройки

- [ ] Бот добавлен в администраторы канала @avtoshkolavtelefone
- [ ] У бота есть права на просмотр участников канала
- [ ] Канал публичный
- [ ] Username канала правильный (без @)
- [ ] Токен бота правильный
- [ ] Сервер запущен на localhost:8000
