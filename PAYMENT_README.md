# 💳 Система оплаты видеоуроков EasyDrive

## 📋 Структура

### Основные файлы для оплаты:

1. **videos.html** - фронтенд (пользовательский интерфейс)
   - Функция `processCardPayment()` - обработка оплаты картой
   - Отправка данных на бэкенд через `/api/tbank-init-payment`
   - НЕ содержит секретных ключей (вся безопасность на бэкенде!)

2. **server.py** - бэкенд (веб-сервер)
   - Эндпоинт `/api/tbank-init-payment` - инициализация платежа
   - Генерирует токен для Т-банк API
   - Отправляет запросы в Т-банк

3. **tbank_payment.py** - модуль для работы с Т-банк API
   - Класс `TbankPayment` - основной класс для платежей
   - Метод `_create_simple_token()` - генерация токена (SHA-256 + сортировка)

4. **tbank_config.py** - конфигурация
   - Загружает данные из `config.env`

5. **config.env** - секретные данные (НЕ в Git!)
   - Терминальный ключ
   - Секретный ключ
   - URL-ы

## 🔄 Как работает оплата:

```
Пользователь → videos.html → /api/tbank-init-payment → server.py
                                         ↓
                                    tbank_payment.py
                                         ↓
                              Т-банк API (https://rest-api-test.tinkoff.ru/v2/Init)
                                         ↓
                              Ответ → localStorage (активация подписки)
```

## 🔐 Безопасность:

- ✅ SecretKey только на бэкенде
- ✅ Фронтенд получает только публичные данные
- ✅ Токен генерируется на сервере
- ✅ Все запросы идут через бэкенд
